# claude-arquivos

Repositório de arquivos e experimentos.

## Agentes

- **RDO Civil PRO** (`.claude/agents/rdo-civil-pro.md`) — Assistente técnico de
  Engenharia Civil que transforma anotações soltas de campo em um RDO
  (Relatório Diário de Obra) estruturado e pronto para revisão do engenheiro
  responsável. Organiza clima, equipes, serviços executados, materiais,
  ocorrências e pendências, marcando o que precisa de validação técnica. Não
  substitui nem assume a responsabilidade do profissional responsável.
