# claude-arquivos

Repositório de arquivos e experimentos, usado para aprender o fluxo de
contribuição no GitHub (branches, commits e pull requests).

## Estrutura

Por enquanto o repositório contém apenas a documentação inicial. Novos
arquivos e projetos serão adicionados conforme forem criados.

## Como contribuir

1. Crie uma branch a partir da `main`.
2. Faça suas alterações com commits pequenos e descritivos.
3. Abra um pull request para a `main` e peça uma revisão.
